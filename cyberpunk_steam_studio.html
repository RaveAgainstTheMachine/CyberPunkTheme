06 // Complete Instructions, File Architecture & Millennium Setup Guide

NIGHT CITY NETRUNNER MANUAL // v2.2.0
01. Studio & Fullscreen Controls
  • Fullscreen Mode (⛶ Fullscreen): Click the top-right yellow button (or press F11) to expand the studio across your entire monitor.
  • Expand Viewport (◀ Hide Controls): Collapses the left customizer sidebar so the Steam preview stretches to 100% width with zero cutoff.
  • Viewport Switcher: Toggle between LIBRARY // GAME PAGE, STORE // HERO CAROUSEL (hover the side-peek capsules to preview the 45×108px arrow highlight), and TOGGLE TOP MENU.
  • Live Code Compilation: Every color, slider, and layout button automatically recompiles all 7 tabs in real time.
02. Millennium File Architecture

Place all theme files inside:
C:\Program Files (x86)\Steam\millennium\themes\Cyberpunk2077\

  • skin.json — Theme manifest & UI toggles
  • libraryroot.custom.css — Main Steam Desktop & Library HUD
  • libraryroot.custom.js — Docked Friends + Play Bar telemetry
  • webkit.css — Store, Community, Carousel & Edge Arrows
  • friends.custom.css — Standalone Friends & Chat styling
  • options/*.css — Modular layout option stylesheets
03. Applying & Hot-Reloading
  1. In Steam, open Steam → Millennium → Themes and select Cyberpunk 2077 // Night City HUD.
  2. Click the ⚙ Gear / Edit icon next to the theme in Millennium to toggle Games Panel Position, Docked Friends Panel, Gamepage Info Column, or Store Hero Ribbon.
  3. Hot-Reload CSS/JS: Click inside the Steam Library or Store window and press Ctrl + R (or click the Store URL bar refresh icon) to apply edits immediately.
  4. Resize Docked Friends: Drag the vertical cyan divider on the inner edge of the Docked Friends panel to resize its width (`180px`–`500px`).
04. Sharing, Privacy & Clean-Room Info
  • 100% Zero PII: No SteamIDs, account names, tokens, or local user paths are stored anywhere in the theme. Friends list and player telemetry are queried dynamically at runtime on each user's client.
  • Share with Friends: Zip the Cyberpunk2077 folder and have your friend extract it into Steam/millennium/themes/Cyberpunk2077.
